1. users

10 Columns • Primary Entity

Stores student and administrator credentials, profiles, academic affiliation, and role permissions.

Column Type Constraints & Keys Nullable Default Description & Business Rules
idINTEGERPK AUTOINCNONoneUnique primary identifier for user account
nameVARCHAR(120)NOT NULLNONoneFull legal or display name of student / admin
emailVARCHAR(180)UNIQUE INDEXNONoneInstitutional email address (login credential)
password_hashVARCHAR(255)NOT NULLNONoneCryptographically salted password hash (pbkdf2:sha256)
roleVARCHAR(20)NOT NULLNO'student'Authorization role: 'student' or 'admin'
collegeVARCHAR(180)NULLABLEYESNoneEnrolled college / university institution name
bioTEXTNULLABLEYESNoneStudent biography, academic interests & background
availabilityVARCHAR(120)NULLABLEYESNonePreferred study hours (e.g. "Weekends & Evenings")
created_atDATETIMENOT NULLNOUTC_NOWAccount creation timestamp (UTC)
updated_atDATETIMENOT NULLNOUTC_NOWProfile last updated timestamp (UTC, onupdate)
Relationships: 1-N user_skills, sent_requests, received_requests, given_ratings, received_ratings.

2. skill_categories

5 Columns • Taxonomy Entity

Standardized academic taxonomy groupings for classifying platform skills into technical/creative disciplines.

Column Type Constraints & Keys Nullable Default Description & Business Rules
idINTEGERPK AUTOINCNONoneUnique category primary identifier
nameVARCHAR(80)UNIQUE NOT NULLNONoneCategory name (e.g., "Programming & Tech", "Database", "Design")
descriptionVARCHAR(255)NULLABLEYESNoneOverview of subjects covered in this category
iconVARCHAR(50)NOT NULLNO'bi-tag'Bootstrap Icons CSS class for UI visual badge
created_atDATETIMENOT NULLNOUTC_NOWTaxonomy creation timestamp (UTC)
Relationships: 1-N skills (cascade all, delete-orphan).

3. skills

5 Columns • Catalogue Entity

Canonical catalogue of predefined and student-proposed skills available for peer exchange.

Column Type Constraints & Keys Nullable Default Description & Business Rules
idINTEGERPK AUTOINCNONoneUnique skill primary identifier
category_idINTEGERFK NOT NULLNONoneForeign key linking to skill_categories.id
nameVARCHAR(100)UNIQUE INDEXNONoneStandardized skill name (e.g. "Python", "SQL", "Figma")
descriptionVARCHAR(255)NULLABLEYESNoneSummary curriculum or domain details
created_atDATETIMENOT NULLNOUTC_NOWSkill registration timestamp (UTC)
Deduplication Policy: Automated case-insensitive resolution reuses existing skill ID when student enters custom name.

4. user_skills

8 Columns • Junction / Associative Entity

Junction table mapping student portfolios to skills with teaching/learning intent and proficiency.

Column Type Constraints & Keys Nullable Default Description & Business Rules
idINTEGERPK AUTOINCNONoneUnique junction record identifier
user_idINTEGERFK INDEXNONoneStudent ID referencing users.id
skill_idINTEGERFK INDEXNONoneSkill ID referencing skills.id
skill_typeVARCHAR(10)NOT NULLNONoneIntent type: 'teach' (offering) or 'learn' (seeking)
proficiencyVARCHAR(20)NOT NULLNO'intermediate'Proficiency: 'beginner', 'intermediate', 'advanced'
notesVARCHAR(255)NULLABLEYESNoneCustom student notes, target frameworks, or topic focus
created_atDATETIMENOT NULLNOUTC_NOWRecord addition timestamp (UTC)
updated_atDATETIMENOT NULLNOUTC_NOWRecord last modified timestamp (UTC, onupdate)
Table Constraint: UNIQUE(user_id, skill_id, skill_type) prevents adding duplicate skills for same intent.

5. exchange_requests

9 Columns • Proposal Entity

Bilateral skill swap proposals initiated by one student to another with offered and requested skills.

Column Type Constraints & Keys Nullable Default Description & Business Rules
idINTEGERPK AUTOINCNONoneUnique exchange proposal identifier
sender_idINTEGERFK INDEXNONoneInitiating student ID referencing users.id
receiver_idINTEGERFK INDEXNONoneRecipient peer student ID referencing users.id
offered_skill_idINTEGERFK NOT NULLNONoneSkill sender teaches, referencing skills.id
requested_skill_idINTEGERFK NOT NULLNONoneSkill sender wants to learn, referencing skills.id
statusVARCHAR(20)NOT NULLNO'pending'State: 'pending', 'accepted', 'rejected', 'cancelled'
messageTEXTNULLABLEYESNoneIntroductory proposal message and schedule preferences
created_atDATETIMENOT NULLNOUTC_NOWProposal sent timestamp (UTC)
updated_atDATETIMENOT NULLNOUTC_NOWStatus transition timestamp (UTC, onupdate)
Business Rule: sender_id != receiver_id prevents self-proposals. Accepted proposals unlock session scheduling.

6. exchange_sessions

10 Columns • Operational Session Entity

Scheduled learning meetings originating from accepted exchange requests.

Column Type Constraints & Keys Nullable Default Description & Business Rules
idINTEGERPK AUTOINCNONoneUnique session identifier
request_idINTEGERFK UNIQUENONoneParent accepted request ID referencing exchange_requests.id
scheduled_atDATETIMENOT NULLNONoneDate and time of meeting
duration_minutesINTEGERNOT NULLNO60Planned meeting length in minutes (default 60)
modeVARCHAR(20)NOT NULLNO'online'Delivery format: 'online', 'in_person', 'hybrid'
meeting_detailsVARCHAR(255)NULLABLEYESNoneVideo call URL (Meet/Zoom) or physical campus room
notesTEXTNULLABLEYESNoneSession agenda, study materials, or preparation topics
statusVARCHAR(20)NOT NULLNO'scheduled'Session state: 'scheduled', 'completed', 'cancelled'
created_atDATETIMENOT NULLNOUTC_NOWSession booking timestamp (UTC)
updated_atDATETIMENOT NULLNOUTC_NOWSession modification timestamp (UTC, onupdate)
Unique 1-to-1 Constraint: request_id is UNIQUE; allows in-place rescheduling after cancellation.

7. ratings

7 Columns • Evaluation Entity

Mutual post-session peer ratings and qualitative reviews following completed learning sessions.

Column Type Constraints & Keys Nullable Default Description & Business Rules
idINTEGERPK AUTOINCNONoneUnique evaluation record identifier
session_idINTEGERFK INDEXNONoneCompleted session ID referencing exchange_sessions.id
reviewer_idINTEGERFK INDEXNONoneStudent submitting review referencing users.id
reviewee_idINTEGERFK INDEXNONoneStudent receiving review referencing users.id
scoreINTEGERCHECK 1..5NONoneInteger rating between 1 and 5 stars (inclusive)
feedbackTEXTNULLABLEYESNoneQualitative peer feedback, testimonials & remarks
created_atDATETIMENOT NULLNOUTC_NOWRating submission timestamp (UTC)
Table Constraints: UNIQUE(session_id, reviewer_id) prevents duplicate ratings; CHECK(score BETWEEN 1 AND 5) bounds star ratings.
