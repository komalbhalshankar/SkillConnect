7. ratings

Mutual post-session peer ratings and qualitative feedback submitted after completed learning sessions.
7 Attributes Evaluation / Review Entity
Column Data Type Constraints & Keys Null Default Description & Domain Rules
id INTEGER PK AUTOINC NO — Unique evaluation record identifier
session_id INTEGER FK INDEX NO — Completed session ID referencing exchange_sessions(id)
reviewer_id INTEGER FK INDEX NO — Student submitting review, referencing users(id)

3 Relational Integrity, Cascade & Business Rules
Constraint Unique Intent Constraint
UNIQUE(user_id, skill_id, skill_type) on user_skills guarantees a student cannot create duplicate portfolio records for the same skill and intent combination.
1-to-1 Strict Session 1-to-1 Mapping
UNIQUE(request_id) on exchange_sessions enforces that each accepted proposal generates exactly one scheduled learning meeting.
Check Star Rating Boundaries & Uniqueness
CHECK(score BETWEEN 1 AND 5) enforces valid 1-to-5 star ratings, while UNIQUE(session_id, reviewer_id) prevents duplicate evaluations from the same participant.
Integrity Referential Cascades & Self-Check
Deleting a User cascades across related skills, proposals, and reviews. Business logic enforces sender_id != receiver_id to forbid self-swaps.
